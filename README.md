# Awesome SmartPAL Fellows

Curated list of open-source **reusable artifacts** from the [SmartPAL Fellowship](https://github.com/smartpal-community).

Projects are authored by fellows. Copyright stays with the fellow. Inclusion here is for discoverability only and does not transfer ownership to SmartPAL AI Inc.

## How to get listed

1. Publish the reusable artifact as a **public** repository (under [`smartpal-community`](https://github.com/smartpal-community) and/or your personal account).
2. Use a permissive license with the fellow named in the copyright notice (MIT / Apache-2.0 / BSD for code; CC BY 4.0 / CC0 for non-code).
3. Include the fellowship disclaimer in the README.
4. Optional: add a thin `smartpal-community` **landing-page** repo that links to your canonical owner repo.
5. Open a pull request adding your project below.
