# Awesome SmartPAL Fellows

Curated list of open-source projects from the [SmartPAL AI Fellowship](https://github.com/smartpal-community).

Projects are authored by fellows. Copyright stays with the fellow. Inclusion here is for discoverability only and does not transfer ownership to SmartPAL AI Inc.

## How to get listed

1. Publish a public repository (personal account or [`smartpal-community`](https://github.com/smartpal-community)).
2. Use MIT or Apache-2.0 (or another approved permissive license) with the fellow named in the copyright notice.
3. Include the fellowship disclaimer in the README.
4. Open a pull request adding your project below.
